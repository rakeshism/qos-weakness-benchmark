# QoS weakness benchmark

Code for the paper "Hidden weaknesses in QoS-based service ranking:
a known-answer benchmark of normalisation and aggregation choices".

## Data
Download QWS v2.0 from its original authors (Al-Masri and Mahmoud, 2007)
and place the file as `qws.csv` in this folder.

## Requirements
Python 3.x with numpy, pandas, scipy and matplotlib (see requirements.txt).

## How to run
Open `benchmark_experiments.ipynb` and run all cells in order.
All random seeds are fixed, so the results are reproducible.
